# 007: 楽曲試し聴き機能 詳細設計書の作成

- ステータス: 完了
- 関連文書: [楽曲試し聴き機能 詳細設計](../../docs/superpowers/specs/2026-08-01-track-preview-playback-design.md)

## 概要

楽曲管理画面(`/tracks`)の各行に再生ボタンを追加し、登録済みの `.wav` を
ブラウザ上でその場で試し聴きできるようにする機能の詳細設計。配信用の新規API
(`GET /api/tracks/:id/audio`。Rangeヘッダ非対応、`origin` を問わず許可)、
`TrackRow`/`TrackSection`/`TracksPage` への配線方式(単一の共有 `<audio>` 要素で
同時に鳴るのは常に1曲)、UI外観(ブレインストーミングでモックアップ比較の上
確定した「▶/⏸ボタン + 行全体ハイライト」案)、エラー処理を確定した。

## 完了条件

- [x] 配信API(エンドポイント・エラー形式・Rangeヘッダ非対応の決定)を設計する
- [x] `track-store.ts` への追加関数(`origin` チェックなし)を設計する

- [x] 共有プレイヤーの配線方式(単一 `<audio>` 要素・状態の受け渡し)を設計する
